# relation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。
リレーションを使った「ブログシステム」を作成しました。投稿にコメント（1対多）とタグ（多対多）の関連付けをしました。

## 使用技術
- PHP 8.5.10
- Laravel 10.50.3
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL

## 学んだこと
- １対多のリレーション（hasMany() / belongsTo()）と多対多のリレーション（belongsToMany()）の定義する場所や定義するコードについて学びました。
- Eager Loading(with())を入力することで、N+1問題を回避する仕組みについて学びました。
- Laravel Tinker でデータ作成したときにエラーが出た際は、変数が定義されているかの確認と多対多のリレーションの接続が正しくなっているかを確認してデータを入力し、解決しました。

## 動作確認
http://localhost/posts
にアクセスし、各投稿にコメント数とタグが表示されることを確認しました。
投稿をクリックすると、投稿の内容とコメントの内容が表示されることを確認しました。
投稿のタグをクリックすると、同じタグの投稿が一覧で表示され、タグ検索解除をクリックすると、投稿一覧に戻ることを確認しました。
